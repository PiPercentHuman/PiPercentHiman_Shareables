# Pi Percent Human — Shareables

Things made for Pi Percent Human videos that are worth having in full, not just as a few seconds on screen.

| | |
|---|---|
| [The King of Elfland's Daughter — a manhwa chapter](elflands-daughter-manhwa/) | 38-panel vertical-scroll comic, every panel generated locally with Qwen-Image 2.1 |
| [Manhwa in motion, part 1: a multiplane camera in Blender](manhwa-motion-blender/) | The 38 panels of that chapter turned into 4-second camera shots without redrawing a line: each panel split into depth layers and filmed in Blender. The three scripts, and the whole chapter in motion |
| [Manhwa in motion, part 2: Wan 2.2 redraws every frame](manhwa-motion-wan/) | The same 38 panels redrawn frame by frame by an open video model (Wan 2.2 image-to-video) on a home computer: the ComfyUI driver, the batch script, the on-twos and reverse tricks, the face count, and the chapter cut with both tools |
| [Eight drivers, one highway](jev-driving/) | A decision model, three chatbots, a reasoning model, two local models and thirteen lines of code drive the same simulated traffic: the code, and all 1,220 recorded drives, each replayable from its seed |
| [AgentJournal: a memory for coding agents](https://github.com/PiPercentHuman/agentjournal) | Pin what you were told, journal what you did, sleep when your head is full: a pi extension, a Claude Code plugin and Codex/Copilot hooks that keep an agent's rules and progress across context cuts, with the benchmark behind it (169 recorded trials on a local model). Its own repository, so it can be installed and forked |
| [/finetune: a Claude Code mod that fine-tunes a local model](https://github.com/PiPercentHuman/Claude-finetune-mod) | One command trains a LoRA block for a local model on your own question-and-answer file, and /finetune ask puts the same question to the model with and without it. The mod, the six made-up towns it was tested on, every recorded reply (replay.py scores them again without a model) and the recorded terminal sessions. Its own repository, so it can be loaded with --plugin-dir and forked |
| [Can a model be built like LEGO?](lora-lego/) | A small base model that only knows language and tool calling, LoRA blocks for everything else, and a package manager (blocks.py) that installs the blocks a project needs. Brick, a programming language made up for the test, every recorded reply (replay.py scores all 1,884 again without a model) and the package manager's terminal output |
| [What if the router is the decision model?](decision-inside/) | 517 labelled GitHub issues read out of four open models three ways (asked out loud, from a hidden layer, and from the mixture-of-experts router alone) and raced against Jev, a decision model you pay for. The reading script, the issues, the saved features, and every answer issue by issue (replay.py scores all of them again without a model) |
| [MOSS Image: how to ask it for each kind of job](moss-image/) | A free local image model that can write real words into a picture, run on eight kinds of job (a photo, anime, a poster title, menus of three, eight and twenty dishes, a concert poster as a sentence and as a JSON layout, a comic, a Chinese sign and an edit) beside its 8-step fast mode, its model card's recipe, Qwen-Image 2.1 and plain code. Every prompt and layout, the ComfyUI driver, all 138 generated pictures and every OCR and eye check (replay.py checks all 144 records again) |
| [AgentJournal as a Claude Code mod](https://github.com/PiPercentHuman/agentjournal/tree/main/mod) | A mod that answers Claude Code's compaction itself, like a ward chart: your instructions pinned word for word, one line for every action, the last few steps kept, no model called; and it clears the conversation itself when a topic is done. Raced against Claude Code's own summary, keeping everything, a plain cut and last version's hooks: 30 headless Claude Code jobs, six seeded worlds each, every run recorded (replay.py scores all 30 again without a model). Inside the AgentJournal repository, so it loads with --plugin-dir |
| [Anime with Wan 2.1: a general anime style LoRA and a chapter-to-episode pipeline](anime-lora-wan/) | A free anime style LoRA for the small Wan 2.1 text-to-video model (1.3B) that draws anime from any prompt, two example character LoRAs that keep their faces from shot to shot (the LoRAs and the ComfyUI workflow are on [Hugging Face](https://huggingface.co/anyze/wan2.1-anime-lora)), and the pipeline that turns a chapter into an episode: shots, voices, sound effects, the cut, and training your own LoRAs |
